# Punn Digital

Static HTML website. Open index.html in a browser; no build step required.

Upload the contents of this directory to the repository root.
All styles, scripts, fonts and images are local under assets/.
Demo, login, blog and contact links point to the existing Punn services.
Interactive examples are illustrative and do not connect to a live AI service.

Bootstrap 5.3.8 is included with its license header. Hotel photos are sourced from Unsplash.
The WhatsApp phone illustration is AI-generated; the logo was supplied by the site owner.
